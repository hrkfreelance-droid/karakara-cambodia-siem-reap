# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

delegated: static HTML/CSS/JavaScript for a lightweight Netlify-ready mobile site

## Users

[Inferred from the brief] Visitors deciding what to do before visiting KARAKARA in Siem Reap, primarily on a phone.

## Product Purpose

[Inferred] Put the three practical next actions—call, find the store, and view the menu—within immediate reach.

## Positioning

The page is a focused store-access surface rather than a multi-page restaurant brochure.

## Operating Context

Mobile web, variable connection quality, and browser differences in embedded PDF support are expected.

## Capabilities and Constraints

- One-page static site with relative asset paths.
- Call and Location links activate only after confirmed values are entered.
- Menu opens the supplied PDF directly in the browser, without an intermediate page or custom viewer.
- Foodpanda opens the supplied Siem Reap store URL through a normal HTTPS link; app launch is environment-dependent and is not claimed as verified here.
- Store information sits directly on the background with a localized dark gradient instead of a large translucent card.
- The supplied folder provides the logo SVG, background PNG, and menu PDF; confirmed phone, hours, address, and Maps data are wired from the provided Maps listing.

## Brand Commitments

- Preserve the supplied KARAKARA name and any future supplied logo without altering it.
- Use a black / dark gray / white base with a red accent.
- Keep translucency restrained and legibility-first.

## Evidence on Hand

- User brief: KARAKARA Cambodia, Siem Reap-first, mobile-first, Netlify-ready.
- Local assets in use: `assets/logo.svg`, `assets/background.png`, and `assets/menu.pdf`.
- Confirmed listing data in use: `097 367 4978`, `Sivutha Blvd, Krong Siem Reap`, and Mon–Sat 11:00–21:30 / Sun closed.

## Product Principles

- Make the next action obvious within seconds.
- Never fabricate store facts.
- Keep the page light, legible, and resilient when a PDF viewer is unavailable.
